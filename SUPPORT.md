# Support

## Free / community

| I want to…                     | Go here                                                                                                            |
| ------------------------------ | ------------------------------------------------------------------------------------------------------------------ |
| Report a bug                   | [Open an issue](https://github.com/BrandonClark65/Apex-Agent-Orchestrator/issues/new?template=bug_report.yml)      |
| Request a feature              | [Open an issue](https://github.com/BrandonClark65/Apex-Agent-Orchestrator/issues/new?template=feature_request.yml) |
| Ask "how do I…" or "should I…" | [Start a Discussion](https://github.com/BrandonClark65/Apex-Agent-Orchestrator/discussions)                        |
| Report a security issue        | [SECURITY.md](SECURITY.md) - email, not a public issue                                                             |
| Get unstuck on install         | [docs/INSTALL.md](docs/INSTALL.md#troubleshooting) first, then a Discussion                                        |

I read everything. Response time is best-effort - this is a side project, not a product with
an SLA. Most questions get an answer within a few days.

**To get a fast, useful answer**, include: your package version, the LLM provider you're on,
and the `Agent_Step__c` trace from the failing run (Run Monitor → open the run → the step
timeline). Nearly every "the agent didn't do what I expected" question is answerable from the
trace.
